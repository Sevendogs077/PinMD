## ✨ 主要特性

#### 👻 幽灵模式 (Ghost Mode)
> 开启 **鼠标穿透**，悬浮于桌面顶层但不遮挡底下的任何窗口操作。
> <br> ⌨️ 快捷键：<kbd>Alt</kbd> + <kbd>Shift</kbd> + <kbd>Z</kbd>

#### 🔥 热更预览 (Hot Reload)
> **实时监视** 本地 `.md` 文件变化并毫秒级渲染，无需手动刷新，保存即更新。

#### 🎨 自定义外观 (Custom Style)
> 支持自由调整窗口 **透明度**、字体大小及代码高亮配色，完美融入你的桌面壁纸。
