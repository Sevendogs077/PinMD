## 简介

一个极简的桌面悬浮 Markdown 便签。

## 特性
- **幽灵模式**：`Alt + Shift + Z` 开启鼠标穿透，不遮挡操作。
- **热更预览**：实时监视 MD 文件变化并渲染。
- **自定义外观**：可调整透明度、字体大小和高亮颜色。
